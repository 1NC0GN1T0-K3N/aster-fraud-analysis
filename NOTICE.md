# Attribution and release scope

Fraud Analytics is an academic portfolio project by Kyaw Thiha (Kendrick), developed for ITCY514 at Mahidol University. Aster Field Services and all associated identities, accounts, policies and records are fictional.

The repository contains the author's expense-case implementations and analytical evidence. It excludes other students' datasets and reports, course lecture materials, private correspondence and the peer role-play verdict. AI assisted code and writing; executable analytical code produces the measurements.

Python and JavaScript libraries, Node.js, n8n, PostgreSQL and Gemini are third-party projects/services with their own licenses and terms. The optional exports require the reader's own service configuration and credentials. No third-party endorsement is implied.
